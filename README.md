# IA03 – Pol Martí

Activitats de Flutter del mòdul DAM – Aplicacions Multiplataforma (curs 25/26).

## Estructura

| Carpeta | Descripció |
|---|---|
| `activitat1_dialogs` | Activitat 1: Entrada de dades amb 4 tipus de diàlegs (SnackBar, ModalBottomSheet, AlertDialog, SimpleDialog) |
| `activitat2_forma` | Activitat 2: Anàlisi i comentari del FormA amb Flutter Form Builder |
| `activitat3_forms` | Activitat 3: Implementació dels formularis B, C i D amb Flutter Form Builder |

## Execució

```bash
cd activitat1_dialogs   # o activitat2_forma / activitat3_forms
flutter pub get
flutter run
```
